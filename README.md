# Habit Tracker (ردیاب عادت‌ها)

یک برنامه وب ساده برای ثبت عادت‌های روزانه و دیدن استریک (تعداد روزهای پشت‌سرهم).

پروژه درس توسعه نرم‌افزار

## امکانات

- افزودن و حذف عادت
- ثبت «انجام دادم» برای هر روز
- محاسبه خودکار استریک
- ذخیره داده‌ها در مرورگر (با localStorage)
- نمایش تاریخ امروز

## ساختار پروژه

| فایل | کاربرد |
|------|--------|
| `index.html` | ظاهر صفحه |
| `app.js` | رفتار صفحه (افزودن، نمایش، ذخیره) |
| `streak.js` | منطق محاسبه استریک |
| `streak.test.js` | تست‌های خودکار منطق استریک |

## اجرای برنامه

فایل `index.html` را در مرورگر باز کنید.

## اجرای تست‌ها

ابتدا Node.js را نصب کنید، سپس:

```
npm install
npm test
```

## ورژن کنترل

پروژه با Git مدیریت شده است. تغییرات در commitهای کوچک ثبت شده و یک ویژگی (نمایش تاریخ) در شاخه جداگانه `feature/show-date` ساخته و با Pull Request به `main` اضافه شده است.
